# YouTube Home Filter: Industrial Standard

[English](README.md) | **繁體中文**

過濾 YouTube 首頁影片的 Tampermonkey 使用者腳本。可依年齡、類型、觀看進度隱藏影片，用白名單保留在意的頻道，並且不必打開三點選單就能對推薦內容做出回饋。

## 安裝

1. 安裝 [Tampermonkey](https://www.tampermonkey.net/)（Firefox 或 Chrome）。
2. [**安裝腳本**](https://raw.githubusercontent.com/bgtsai/youtube-home-filter/main/youtube-home-filter.user.js)
3. 重新整理 YouTube 首頁，畫面下方會出現控制膠囊。

已啟用自動更新，推送新版本後 Tampermonkey 會主動提示。

## 功能

### 依年齡過濾

隱藏超過指定時間的影片，單位從秒到年都可以。判斷依據是每張卡片上的「x 個月前」後設資料，所以在任何介面語言下都能運作。

### 依類型過濾

每種類型各有獨立開關：

| 類型 | 說明 |
|---|---|
| 一般影片 | 隱藏下列特殊類型「以外」的全部影片——想要一個只剩直播或播放清單的首頁時很好用 |
| 直播影片 | 正在播出中 |
| 預約／首播 | 以卡片上的「通知我」按鈕偵測，不靠關鍵字，因此與語言無關 |
| 音樂 | 以音樂徽章圖示偵測 |
| 會員專屬 | 以會員徽章圖示偵測 |
| Podcast | |
| 混合輯 | |
| 播放清單 | |

### 依觀看進度過濾

依 YouTube 畫在縮圖上的進度條，隱藏看過的影片。兩個獨立門檻，任一達成即視為已看過：

- **百分比**——例如看過 3% 就隱藏
- **絕對秒數**——例如看過 15 秒就隱藏

第二個門檻之所以存在，是因為三小時的影片 3% 就超過五分鐘了。

### 標題關鍵字過濾

依自訂的關鍵字或正規表達式清單，隱藏標題命中的影片。

### 頻道白名單

兩份獨立白名單，優先權高於類型過濾，可以在隱藏整個類別的同時保留特定頻道：

- **音樂白名單**——隱藏音樂時仍保留這些頻道
- **會員白名單**——隱藏會員專屬內容時仍保留這些頻道

把滑鼠移到卡片上點頭像按鈕即可加入，也可以直接在白名單面板裡輸入。

### 快速回饋按鈕

滑鼠移到卡片上會出現按鈕，直接送出 YouTube 自己的回饋動作，不必打開三點選單：

- **不要推薦此頻道**
- **我不喜歡這部影片**——一鍵送出移除與原因
- **不感興趣**
- **我已經看過這部影片**——一鍵送出移除與原因

每個動作都會顯示可復原的通知卡。要顯示哪些按鈕可以自行設定，預設只顯示前兩個。

移除過的影片在該次頁面工作階段內不會再出現，即使首頁重新渲染也一樣。

### 其他

- **自動補抓**——過濾後影片太少時自動捲動載入更多
- **格線欄數**——自訂每列顯示幾部影片（預設 4）
- **增強 tooltip**——滑鼠懸停時顯示完整、未截斷的影片標題
- **在新分頁開啟連結**
- **淺色／深色／自動主題**
- **多語系介面**，附自訂語系編輯器，以及可調整偵測關鍵字的自訂關鍵字編輯器

## 相容性

在 **Firefox + Tampermonkey** 上開發與測試。**Chrome** 同樣支援：腳本會建立 Trusted Types policy，讓介面能在 YouTube 於 Chrome 強制啟用 Trusted Types 的情況下正常渲染。

所有 DOM 選擇器集中在檔案前段的 `YT_SELECTORS` 物件裡。YouTube 改版時，通常只需要修改這一個物件。
